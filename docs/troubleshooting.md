# 常见问题

## 脚本已启用，为什么没有面板？

先确认打开的是用户空间的「收藏」页，地址形如 `https://space.bilibili.com/用户UID/favlist`。B 站首页和视频播放页不会显示该面板。

本次定位到以下启动问题：

- 旧版个人空间与新版 VUI 使用不同 DOM，原代码只识别新版。不同用户看到的界面不同，会出现有人可用、有人不显示的情况。
- 原代码等待页面加载后只检查一次；收藏侧栏晚加载，或从空间首页通过站内导航进入收藏页时，可能错过初始化。
- 2.1.0 的初始化清理对 `window` 使用了 `delete`，在 Tampermonkey 沙箱中会报 `deleteProperty` 错误，导致面板无法启动。2.1.1 改为赋空值，并加入沙箱代理回归测试。
- 当前实测页面长时间停留在 `interactive` 状态，`document-idle` 时未观察到脚本启动。2.1.1 改为 `document-start` 后，在同一页面无需等待加载完成即可启动。

2.1.1 包含两版适配、持续检测和沙箱启动修复。仓库修复版尚未发布到 Greasy Fork，旧安装不会因本地构建自动更新，安装方法见 [README](../README.md)。

更新后刷新收藏页。如果曾点击「点我销毁」，从 Tampermonkey 的脚本菜单选择「显示收藏夹管理面板」。确认扩展有当前站点访问权限，且浏览器允许扩展执行用户脚本；不同 Chrome 与 Tampermonkey 版本的设置入口可能不同。

超过 15 秒仍没有识别出侧栏时，修复版会显示状态提示并继续等待。反馈时请提供脚本版本、收藏页 URL、是否有「体验新版」入口、面板日志或控制台报错，便于判断是脚本未注入还是页面识别失败。

## 为什么复制他人的收藏夹时会跳转？

脚本先到自己的收藏页确认并创建目标收藏夹，再返回源收藏页通过原生复制弹窗操作。等待自动跳转完成，期间不要手动切换用户空间。

## 为什么复制失败或只复制了一部分？

检查面板日志和目标收藏夹的实际结果。网络延迟、失效或无权限的视频、页面改版、分页失败都可能影响结果；当前流程包含固定等待时间，无法保证所有加载速度下都成功。

如果日志提示无法进入批量模式，而自己的收藏夹为空，可先手动创建目标收藏夹，并让用于打开复制弹窗的源收藏夹至少有一个可操作视频。

本次修复验证了启动和弹窗交互，未在真实账号提交完整复制流程。遇到复制中断时，请先核对已有结果，再决定是否重试。

## 文件夹名称有空格会重复创建吗？

2.1.2 修复了首尾空白的比较不一致：页面读取的是 `学习 资料`，而目标输入为 ` 学习 资料 ` 时，旧逻辑会误判为不存在。新版在读取、比较、创建及跨页任务恢复时统一去掉首尾空白，复用已有目标，并对待创建目标去重。

名称内部空格会保留，`学习 资料` 与 `学习  资料`（两个空格）仍视为不同名称。普通内部空格本身未在本次测试中复现重复创建。

如果提示「未确认创建成功」，先检查自己的收藏夹列表。脚本已发送一次新建请求，但未在等待时间内看到目标；此时会停止，不再换入口提交，也不会在刷新后自动重试。网络较慢时可能实际上已经创建成功，核对后再操作。
