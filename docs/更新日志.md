# 更新日志

## 2.1.1（本地修复版，尚未发布到 Greasy Fork）

- 修复 Tampermonkey 的 Window 代理拒绝删除属性，导致首次初始化和面板重新打开失败的问题；改为赋空值释放引用。
- 执行时机改为 `document-start`，不再等油猴的空闲注入时机；页面 DOM 尚未出现时继续等待收藏栏。
- 增加拒绝删除属性的沙箱代理回归测试，覆盖启动、离开收藏页、返回和重新打开。

## 2.1.0（本地修复版，尚未发布到 Greasy Fork）

- 拆分旧版个人空间与新版 VUI 适配器，加入旧版收藏页识别及操作选择器。
- 修复侧栏慢加载和从空间首页通过 SPA 导航进入收藏页时不显示面板的问题。
- 异步刷新收藏夹列表时保留勾选和目标名称，同一用户切换收藏夹保留面板。
- 增加油猴菜单重新显示面板，清理销毁后的鼠标监听，防止重复挂载。
- 排除隐藏的预渲染弹窗，全选操作避免取消已有选择。
- 增加自动回归测试，README 精简为联系方式、安装和使用，技术说明移入 docs。
