# 顶层设计与自主追问

使用 grilling 的依赖顺序：用户任务 → 信息架构 → 页面状态 → 数据语义 → 跨页契约 → 验收。按用户要求自主回答。domain-modeling 术语见 GLOSSARY.md。ui-ux-pro-max 提供简洁、对比度、键盘、反馈原则；自动推荐的营销 Hero、外部英文字体不适用，舍弃。采用桌面工具密度、中文系统字体和原生控件。

## 第一轮：打开脚本
| 自主问题 | 决策和依据 |
| --- | --- |
| 用户首先需要什么？ | 当前空间可复制列表及目标名；默认复制，现有 DOM 即展示，统计/管理不自动扫描。 |
| 首屏需要读什么？ | 来源→目标、列标题、一句同名复用与来源保留。零行隐藏搜索/全选/0计数。 |
| 窗口多大？ | 600×500，左工作区约326px、记录约272px；相较640×600缩窄左区并恢复原高度。支持拖动缩放，窄于560px记录置底。 |
| 日志要隐藏吗？ | 默认侧边可见，独立滚动，可收起且保留上下文。 |

## 第二轮：每个界面
共同骨架：标题/数字版本/记录/最小化/关闭 → 三功能导航 → 左工作区与右记录 → 左下当前功能结果及主要动作。列表和记录独立滚动，无嵌套列表滚动。

```text
收藏夹管理 v2.2.1                 记录 最小化 关闭
复制收藏夹     统计     管理
┌ 工作区（约326）           ┬ 操作记录（约272） ┐
│ 当前范围/直接切换按钮     │ 当前功能 / 级别   │
│ 搜索              全选   │ 时间 级别 阶段    │
│ 已选 n / m               │ 具体事件内容      │
│ 列表（主要阅读空间）     │                   │
├ 当前功能结果 + 主要动作  │ 清空 / 导出       │
└──────────────────────────┴───────────────────┘
```

**复制**：来源/目标同行；选择后动作标数量；空目标就地提示并禁止提交。跨页创建/返回属于同一复制任务；显示最后已确认项目，未确认提交标为待核对。

**统计**：直接显示“当前空间 / 我的订阅”与加载按钮；加载后搜索/全选和列表。页底主动作统计选中；结果展示覆盖、唯一/重复/未知、已知时长和导出。未完整读取不能称账号总数。

**管理**：切换按钮使用动作语言“删除收藏夹 / 取消订阅”；一行后果说明与列表。受保护项目显示原因，普通项无重复警告。预览后集中展示名字、ID、所有者、数量和后果，复选确认才能提交。

**记录**：默认当前功能加系统事件，可选全部功能与级别；显示本地时间、级别、短任务 ID/阶段。跨页交接携带仅属于同一复制任务的有界日志快照，合并去重。导出有 schemaVersion、事件 ID、ISO 时间、功能、任务 ID、阶段、脱敏消息。恢复保留任务 ID，新任务用新 ID。

## 第三轮：状态与边界
| 状态 | 反馈和操作 |
| --- | --- |
| 初始/空 | 一句引导，无无效搜索与0/0。 |
| 读取中 | 当前功能状态；锁定冲突操作，保留记录/最小化。 |
| 列表就绪 | 数量在工具条，不在底部永久显示列表加载成功。 |
| 选择/筛选 | 只批选匹配且合格项目；筛选外选择保留并提示。 |
| 执行中 | 计数只来自观察结果，不虚构总数。 |
| 完成/失败/待核对 | 当前功能展示一次具体结果，入口不再次包装错误。 |
| 切换功能 | 保留独立选择、复制编辑、滚动、任务状态；确认失效，不请求。 |
| 换范围/重载/写操作后 | 清理旧目录、选择、报告及确认，避免过期导出。 |

三份 OperationState；复制由 manager.operation 持有。InventoryPanel 复用加载/选择组件，统计与管理各自选择；目录是显式共享快照，换范围清理两者，实际写操作后废弃目录。避免引入第二份可过期目录。

## 第四轮：数据与跨页契约
is_kid_playlist 接受 boolean false 和历史 numeric 0；true/1、缺失、未知继续保护，第一项保护维持，身份/类型/可用性继续复核，不靠名称放行。

跨页记录增加 operationId 与 journal，兼容旧记录。预期页面验证后先合并诊断与绑定任务，再消费执行状态。日志不能成为执行队列。已提交无成功提示是 unknown，停止并核对，不自动重放。

保留 DOM 复制与不确定停止机制，改进错误和提示观察，不在未授权真实对象时更换为新的复制 API。GM 完整导航仍属未验证边界。

## 工业界文档对应
本 PRD、线框、状态矩阵、术语、数据/交互契约、验收记录对应工业界常用的需求、IA、交互规格与测试说明。常规尺寸易逆转，无需 ADR；诊断与执行恢复边界单独记录决策。
