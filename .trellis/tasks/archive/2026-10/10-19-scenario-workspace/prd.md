# 场景驱动的工作区与跨页任务重构

## Goal

打开脚本立即看到可操作列表，少读说明；明确对象可选性、任务归属、跨页连续性与已确认结果。用户要求自主提问/回答后系统重构，授权本地实现、验证、提交与归档，禁止推送、发布和未指定对象的真实账号写操作。

## Requirements

- 使用 ui-ux-pro-max、grill-with-docs 及依赖，按 inline 工作流先设计后实施。
- 默认紧凑窗口、缩窄左区、侧边记录，统计/管理直接切换范围，共用搜索与全选规则。
- 三功能状态隔离；跨页任务日志连续、规范、可过滤，不重复包装错误。
- 真实只读接口返回 is_kid_playlist:boolean，旧代码 false !== 0 导致普通项受保护。接受布尔与数字表示，未知仍保护。
- 私有日志显示已提交复制但无成功提示，旧界面误泛化为失败；区分明确失败与待核对。

## Acceptance Criteria

- [x] 默认600×500，常规短名称桌面复制/管理至少7个完整行；375px和横屏可操作无横向溢出。
- [x] 三页面相同搜索/全选/计数，筛选外选择保留并提示，空列表隐藏无效工具。
- [x] 统计/管理用可见按钮选择范围，不用下拉；显式加载，切换功能无请求。
- [x] 结果随功能切换，空闲不显示，列表读取成功不占永久底栏。
- [x] 普通 false/0 可选，首项/特殊/未知/异常仍保护；真实只读验证，不真实删除。
- [x] 日志含本地时间、级别、功能、任务ID和阶段；跨页保留ID与顺序，默认当前功能，可查全部；有界、脱敏、版本化导出，诊断恢复不触发执行。
- [x] 未观察成功的提交标为待核对，显示步骤和确认数；错误只终止一次，保留执行前消费与后续停止。
- [x] 使用数字2.2.1，包/运行时/面板/构建一致，不发布。
- [x] build、完整测试、合成浏览器和真实只读检查完成，记录GM及真实写操作未验证边界。

## Notes

- 无阻塞产品决策；真实写操作需要指定测试对象，不属于本任务默认验证范围。
