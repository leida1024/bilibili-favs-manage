Investigate deletion through the default captured hybrid transport. The one-use ticket is intentional; the terminal footer currently hides per-item failure details. Live tests use the dedicated browser and console injection, only newly created private temporary folders. Record aggregate evidence, not account IDs/names/screenshots. If legacy cannot be opened, use public legacy components for fixtures and label VUI live checks accurately.
